Entry for the [Make the Judge Laugh in One Line](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) competition on make.fun.

## What it does

`main.py` writes a single original one-liner (107 characters) to `/output/entry.txt`:

> My cat knocked my coffee off the table, looked me dead in the eye, and I swear I heard it say 'rent's due'.

The line was picked by an internal head-to-head tournament over 12 original candidates, judged on the competition's own rubric: gettable in one read, surprising, tight with the laugh landing at the end, fresh, and clean to read out loud.

## Run

```sh
python3 main.py
```

It validates the line (UTF-8, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt` with no trailing newline.
